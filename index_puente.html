📖 Guía de Uso: El Puente Universal

Bienvenido a tu centro de automatización. Aquí tienes la explicación de cada módulo:

📊 Analizador Excel

Sube cualquier archivo de Excel (.xlsx) de tu computadora. El sistema extraerá las primeras 10 filas y te mostrará los datos para que compruebes que se pueden leer correctamente.

🗄️ Consulta SQL

Permite consultar bases de datos usando comandos SQL. Nota de seguridad: Por protección, solo se permiten comandos de lectura (SELECT). Prueba con el que viene por defecto.

🕸️ Espía Web (Scraping)

Pega la URL de cualquier página web (ej. una tienda). El sistema extraerá el título principal de esa página. Ideal para monitorear competidores.

🧠 Predicción de Riesgo (IA)

Usa una red neuronal matemática creada desde cero. Ingresa el nivel de ingresos y deuda de un cliente (del 0.1 al 1.0) y la IA te dirá si es un cliente seguro o de alto riesgo.
